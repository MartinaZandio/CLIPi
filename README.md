# CLIPi
R workflow for longitudinal CLIPi computation in mycosis fungoides using EHR-derived data

This repository contains the R code developed for the Final Degree Project:

**Design and development of a tool for the computation of the CLIPi prognostic index for patient stratification in mycosis fungoides using data extracted from the electronic health record.**

## Project overview

The code implements a workflow for preprocessing retrospective clinical data, identifying CLIPi-related prognostic variables, reconstructing longitudinal patient event tables, computing CLIPi scores over time, and performing survival analysis.

## Repository contents

- Data extraction and preprocessing scripts
- Cohort identification and filtering procedures
- Rule-based NLP scripts for pathology reports
- Longitudinal event table construction
- CLIPi computation scripts
- Survival analysis scripts

## Data availability

Due to patient confidentiality and data protection regulations, the clinical datasets used in this project are not included in this repository.

## Software

The analysis was developed in R using packages for data manipulation, text processing, and survival analysis.
